# Ferry Windows 版の仕様

Mac 版 Ferry（`App/`）と同じ機能・使い勝手の Windows 版を `Windows/` に作るための仕様。
Windows PC 上の Claude Code がこの文書に沿って作業する。

## 前提

- **使う人**: 会社の人（社内向け。一般公開はしない）。画面の言葉はすべて日本語。
- **Mac 版はそのまま残す**。Windows 版は C# で別に作り、Mac 版と**同じ形式のファイル**で接続先を共有する。
- **接続先**: 会社で共有する接続先（Dropbox の共有フォルダ）と、自分だけの接続先の両方を持てる。
- **パスワード**: 共有しない。各自が自分の PC（Windows の資格情報マネージャー）に保存する。
- コードのコメント・コミットメッセージ・画面の文言は日本語（Mac 版と同じ）。

## 技術

| 用途 | 使うもの |
|---|---|
| 言語・ランタイム | C# / .NET（最新の LTS） |
| 画面 | WinUI 3（Windows App SDK）。Windows 11 の見た目（Mica、Fluent） |
| 画面の作り | CommunityToolkit.Mvvm（MVVM） |
| FTP / FTPS | FluentFTP（Explicit・Implicit、パッシブモード、自己署名証明書の扱い） |
| SFTP | SSH.NET（パスワード・秘密鍵、ホスト鍵の確認） |
| 配布と自動更新 | Velopack（インストーラーと自動更新。更新の置き場所は Dropbox の共有フォルダ） |
| パスワードの保存 | Windows の資格情報マネージャー（Credential Manager） |
| 通知 | Windows App SDK の App Notifications |

構成の案:

```
Windows/
  Ferry.sln
  Ferry/            … WinUI 3 のアプリ
  Ferry.Core/       … 画面に依存しない部分（接続先の保存、転送、同期の比較、除外ルール）
  Ferry.Tests/      … Ferry.Core のテスト（xUnit）
  release.ps1       … ビルド → Velopack でまとめる → GitHub のリリースと Dropbox に置く
```

## 機能（Mac 版にあるもの）

### 接続

- FTP / FTPS（Explicit）/ FTPS（Implicit）/ SFTP。
- パッシブモード（既定でオン）。PASV の応答の IP は無視して、制御接続と同じホストにつなぐ（NAT 内のサーバー対策）。
- FTPS の証明書を検証できないとき（自己署名など、Kappe のサーバーが該当）は「証明書を確認できません」画面を出し、「証明書を検証せずに接続」で接続設定の `verifyCertificate` を false にして接続し直す。
- SFTP は初めてのホスト鍵を記録し、2 回目以降に鍵が変わっていたら接続を止める。
- FTP ではファイル名を UTF-8 で扱うよう依頼する（`OPTS UTF8 ON`、失敗しても無視）。
- 一覧表示用・転送用・プレビュー用で**接続を分ける**（転送中でもフォルダを移動できるように）。
- パスワードが未保存、またはログインに失敗したら、右のペインにパスワード入力画面を出す（「保存する」チェック付き）。
- エラーメッセージは日本語で、原因が分かるように（ログイン失敗、ホストが見つからない、タイムアウト、パッシブモードのデータ接続失敗、証明書、権限、見つからない など）。

### 画面

- 左にサイドバー（接続先の一覧）、右に 2 ペイン（左が「この PC」、右がサーバー）、下に転送一覧（転送があるときだけ）。
- サイドバー
  - 上に検索欄（名前・ホスト・ユーザー名・フォルダ名。空白区切りで AND。Enter で最初の結果を開く）。
  - 「会社の共有」のフォルダ → 「会社の共有・フォルダなし」 → 自分のフォルダ → 「フォルダなし」の順。共有の接続先には 2 人のアイコンを付ける。
  - フォルダは開閉でき（名前を押しても開閉）、状態を覚える。
  - 右クリック: ブックマークで開く、編集、複製、フォルダへ移動、会社で共有する／自分だけの接続先にする、削除（共有のものは「全員の一覧から消えます」と確認）。
  - 接続先をフォルダの見出しへドラッグして移せる。
  - 下に Ferry のマークと保存場所の表示。
  - 前回開いていた接続先を、次回の起動時に開く。
- ペイン
  - 見出し（場所の名前、戻る・上へ・再読み込み、メニュー）、パンくず、一覧（名前・サイズ・更新日・権限（サーバー側のみ））、下に件数。
  - サーバー側の見出しには Ferry の青をうっすら敷く。
  - 一覧はフォルダが先。列の見出しで並べ替え。列幅を覚える。隠しファイルの表示切り替え（サーバー側は既定で表示、`.htaccess` を触るため）。
  - 左右のペインの幅は最初は半分ずつ、変えたら覚える。境界線のダブルクリックで半分に戻す。
  - **キー操作**: Delete で削除（ローカルはごみ箱、サーバーは確認してから完全に削除）、Enter で開く、**スペースでプレビュー**。
  - ダブルクリック: フォルダは開く、サーバーのファイルはダウンロード、ローカルのファイルは既定のアプリで開く。
  - 右クリック: アップロード／ダウンロード、エディタで開く（サーバー側）、名前を変更、パーミッション（サーバー側、755 などの数字）、エクスプローラーで表示（ローカル側）、パスをコピー、削除、新規フォルダ、再読み込み。
  - ローカル側の見出しに「フォルダを選択…」「エクスプローラーで開いているフォルダ」「このフォルダをエクスプローラーで開く」。エクスプローラーのフォルダを左のペインへドラッグするとそこへ移動。
- ツールバー: 編集中のファイル、ブックマーク、アップロード、ダウンロード、同期、接続設定。
- 一覧表示は重くならないように: 並べ替えた結果は覚えておき、中身や並び順が変わったときだけ作り直す（Mac 版で、選択のたびに並べ替えて重くなった）。

### 転送

- ドラッグ&ドロップ（左右のペイン間、エクスプローラーからサーバー側へ、**サーバー側からエクスプローラーへ**）。エクスプローラーへのドラッグは、ドロップされたときにダウンロードする仮想ファイルで作る（`StorageFile.CreateStreamedFileAsync` など）。
- フォルダは中身ごと転送。**除外ルール**（下記）はフォルダの中身にだけ適用し、直接選んだ項目には適用しない。
- 同名のファイルがあるときは「新しい場合のみ上書き／すべて上書き／既存のファイルはスキップ／転送をやめる」をまとめて 1 回聞く。
- 転送一覧: 進み具合、中止、再試行、完了した項目の消去。進み具合の画面更新は 0.1 秒ごとに間引く。
- 1 回の操作で始めた転送が全部終わったら、まとめて 1 回通知（設定でオフにできる）。

### プレビュー（Mac 版の Quick Look）

- スペースで開閉、開いたまま ↑↓ で次のファイル。
- Windows に標準の同等機能がないので、アプリ内のプレビュー用ウィンドウを作る（画像、テキスト・コード、HTML・PDF は WebView2）。PowerToys Peek が入っていればそちらを使ってもよい。
- サーバーのファイルは一時フォルダにダウンロードして表示（転送一覧には出さない）。同じサイズのものは使い回す。50MB を超えるものはプレビューしない。
- サーバー側で 5MB までのファイルを 1 つ選んで 0.25 秒止まったら、裏で先にダウンロードしておく（スペースを押したらすぐ開くように）。

### エディタで開いて自動アップロード

- サーバーのファイルを一時フォルダにダウンロードしてエディタで開き、保存を検知するたびにアップロードする（書き込み途中を避けるため、更新日時が 1 回の確認の間変わらなければ書き込み完了とみなす）。
- エディタは既定で VS Code（入っていれば）、設定で変更できる。
- ツールバーの「編集中」メニューで、編集中のファイルの一覧・もう一度開く・監視をやめる。

### 同期

- 左右で開いているフォルダを比べて、サイズが違うか送信元の方が新しい（2 秒より）ファイルを転送する。
- 画面: 送信元・送信先のカードと、間の矢印ボタン（押すと方向を切り替え）。ミラー（転送先にしかないものを削除）のスイッチ。除外ルールの表示。
- 比較の結果: 新規・変更・削除・転送量のタイル（押すと絞り込み）、項目ごとのチェック、調べたフォルダ数の表示、違いが無ければ「同期済みです」。
- 完了したら通知（転送・削除・失敗・中止の件数）。

### その他

- ブックマーク: 接続先ごとに「左のフォルダ + 右のフォルダ」の組み合わせを保存。選ぶと両方のペインがそこを開く。「接続時に開く」を設定できる。
- 除外ルールの既定: `.git` `.svn` `.hg` `node_modules` `.DS_Store` `._*` `Thumbs.db` `desktop.ini` `.idea` `.sass-cache` `__pycache__` `*.swp` `*~` `*.ferrypart`（`*` と `?` が使える。名前だけで判定）。
- 読み込み: Windows では **FileZilla**（`%APPDATA%\FileZilla\sitemanager.xml`）と **WinSCP** からの読み込みがあると便利（Mac 版の Transmit からの読み込みの代わり）。
- 設定画面のタブ: 会社の共有、除外、エディタ、通知。

### Windows 版では作らないもの

- Finder のタグ（Windows に無い）。
- iCloud でのパスワード同期（パスワードは各自の PC に保存する方針のため）。

## データの形式（Mac 版と共通）

### 共有フォルダ（Dropbox）

各自が設定画面で選ぶ（PC ごとに Dropbox の場所が違うため）。中身:

```
<共有フォルダ>/ferry-shared.json      {"version":1}  … 目印
<共有フォルダ>/folders.json           [{"id": "...", "name": "お客様サーバー"}]
<共有フォルダ>/servers/<ID>.json      接続先 1 件（下の形式）
```

- 接続先 1 件につき 1 ファイルにしているのは、複数人が同時に編集しても衝突しにくくするため。
- ファイル名が `<ID>.json` の形でないもの（Dropbox の「競合コピー」など）は読まない。
- 共有フォルダの変更を監視して、他の人の変更をすぐ反映する（FileSystemWatcher）。

接続先の JSON（Mac 版の `ServerConfig` と同じ。キーは camelCase、ID は大文字の UUID 文字列。値が無いキーは省略される）:

```json
{
  "id": "6F1C2E1A-....",
  "name": "山神果樹薬草園",
  "serverProtocol": "ftps",          // "ftp" | "ftps"（Explicit）| "ftpsImplicit" | "sftp"
  "host": "yamagamikaju.kappe.ne.jp",
  "port": 10021,                     // 省略時は既定（ftp/ftps 21、ftpsImplicit 990、sftp 22）
  "username": "...",
  "initialPath": "/www.example.com/wp/wp-content/themes/xxx",
  "passiveMode": true,
  "verifyCertificate": false,
  "folderID": "....",                // サイドバーのフォルダ。省略でフォルダなし
  "localPath": "...",                // ↓ この 4 つは PC ごとの設定なので、共有フォルダには書かない
  "privateKeyPath": "...",
  "bookmarks": [{"id": "...", "name": "テーマ", "localPath": "...", "remotePath": "..."}],
  "startBookmarkID": "..."
}
```

**PC ごとの設定**（`localPath` `privateKeyPath` `bookmarks` `startBookmarkID`）は共有フォルダに書かず、各自の設定に「共有の接続先の ID → PC ごとの設定」として保存する（Mac 版の `SharedServerOverride`）。

### 自分の接続先

`%APPDATA%\Ferry\servers.json`（Mac 版は iCloud Drive の `Ferry/servers.json`）:

```json
{
  "version": 2,
  "servers": [ /* 上の形式 */ ],
  "folders": [ {"id": "...", "name": "..."} ],
  "excludePatterns": [ ".git", ... ],
  "sharedOverrides": { "<共有の接続先の ID>": {"localPath": "...", "bookmarks": [...], "startBookmarkID": "...", "privateKeyPath": "..."} }
}
```

### パスワード

Windows の資格情報マネージャーに、ターゲット名 `Ferry:<接続先の ID>` で保存する。共有の接続先も ID で引くので、共有に移しても保存済みのパスワードはそのまま使える。

## 配布と更新

- 社内向けなので、コード署名は無し（初回に「Windows によって PC が保護されました」→「詳細情報」→「実行」）。
- GitHub のリポジトリは非公開なので、会社の人は GitHub からはダウンロードできない。**Velopack のインストーラーと更新ファイルを Dropbox の共有フォルダ（例: `<共有フォルダ>/App/Windows/`）に置き**、Ferry がそこから自動更新する。GitHub のリリースにも同じものを置く。
- 64 ビット（x64）を基本に、ARM 版 Windows を使う人がいれば arm64 も作る。

## 見た目

- アイコン: Mac 版と同じ折り紙の船（`App/Tools/make-icon.swift` の B3）。`.ico` に書き出して使う。
- テーマカラー: Ferry の青（ライト `#2A6FE0`、ダーク `#4C8DFF`）。
- ダークモードに対応する。

## 進め方

1. `Ferry.Core`: 接続先の保存（自分・共有・PC ごとの設定）、除外ルール、同期の比較。Mac 版の保存ファイルを読めることをテストで確かめる。
2. 接続と一覧表示、2 ペインの画面、サイドバー（共有を含む）。
3. 転送（ドラッグ&ドロップ、上書き確認、転送一覧、通知）。
4. プレビュー、エディタで開いて自動アップロード、同期、ブックマーク。
5. 設定画面、FileZilla / WinSCP からの読み込み。
6. Velopack での配布と自動更新、`release.ps1`。

公開テストサーバー `test.rebex.net`（ユーザー `demo`、パスワード `password`）は FTP / FTPS（Explicit・Implicit）/ SFTP すべてで読み取り専用の動作確認に使える。
