# Windows 版：次のリリースの前に Windows で確かめること

0.1.10 の後に入った変更（不具合の修正と 7 つの機能）は、Mac の上で実装した。
共通部分（Ferry.Core）のテスト 221 件は Mac で通っているが、アプリ本体（`Windows/Ferry`）は Mac でビルドできないので、
**Windows でのビルドと動作はまだ誰も確かめていない**。リリースの前に、下を上から順に確かめる。
終わったら、このファイルは消してよい。

Mac でできた範囲の確認: アプリ本体の C#（画面の定義を除く）のコンパイル、画面の定義（XAML）の部品の名前・イベント・x:Bind・行と列の番号の機械的な照合。
どれも問題は見つかっていない。

**2026-11-11 に Windows で確かめた**（開発版を起動して）:
- 1. ビルド（Debug・Release とも警告 0）とテスト 232 件（ネットワークのものも含む）。設定の 7 つのタブ（「転送」を含む）の切り替え。
- 4. FTPS の案内（印 → 調べる →「証明書も確認できました」）、＋メニューの一括の調べ（途中で閉じると止まる）。xserver では証明書を検証できた。
- 5. マスターパスワードの変更の入力の確認（7 文字・不一致・今のパスワード違い）。実際の変更はしていない。
- 6. 一覧の絞り込み（件数・合わないときの表示・Esc）、サイドバーの検索の全角半角。
- 7. 起動時の一時フォルダの掃除。
- 直したもの: パスワードのタブのボタンが設定の幅からはみ出す → 2 段に。一括の調べの画面の右端（結果の文字）が切れる → 画面を広げた。
  絞り込みを Esc で閉じるとフォーカスが列の見出しに行く → 一覧の行に戻す。

まだ: 2（転送。書き込めるサーバーが要る）、3（エディタの衝突）、4 のホスト鍵と「FTPS に切り替える」、5 の本物の変更と Mac との行き来、8（PDF）。

## 1. ビルドとテスト

1. `git pull` して、ふつうにビルドする。エラーが出たら、まずそれを直す。
2. テストを全部流す（`release.ps1` の最初でも流れる）。Mac で流していないもの:
   - `CredentialPasswordStoreTests`
   - `PasswordVaultTests` の「書き込めないとき」（Windows ではファイルを読み取り専用にする別の経路を通る）
3. 起動して、設定 → 左のタブに「転送」があり、タブを切り替えると正しいページが出る（「転送」を途中に足したので、ずれていないか）。

## 2. 転送

- **並列転送**: 設定 →「転送」で「同時に転送する数」が 3。小さいファイルの多いフォルダ（WordPress のテーマなど）をアップロードして、
  転送一覧で同時に 3 件「転送中」になる。終わった後、両方のペインの再読み込みが 1 回だけ起きる。
- 途中で「全部中止」→ 全部「中止」になる。1 件を「やり直し」→ 完了する。
- 数を 1 にして保存 → 次の転送が 1 件ずつになる。
- パスワードを保存していない接続先に、パスワードを入力してつなぎ、複数のファイルを転送できる（2 本目以降の接続にもパスワードが渡る）。
- **安全なアップロード**: 既存のファイル（できれば権限 600 の `wp-config.php` の写し）を上書きアップロードする。
  送っている間、サーバーに `.名前.ferrypart` が見え、終わると消え、権限が 600 のまま。
  大きいファイルで途中に中止 → 元のファイルが元の中身のまま、一時ファイルが残らない。同期の「変更」でも同じ。
- **直接の上書き**（設定で安全なアップロードをオフ）: 既存のファイルへアップロードして、成功し、権限が変わらない。
- **更新日時**: アップロードした直後に「ダウンロードの同期」で比較して、アップロードしたファイルが「変更」に出ない。

## 3. エディタで開く

- エディタで開く → 別の手段（他の PC、WinSCP など）でサーバー側を書き換える → エディタで保存。
  通知と確認が出て、アップロードされない。「アップロードしない」→ もう一度保存すると、また確認が出る。
  「上書きする」→ その次の保存は確認なしで送る。確認が出ている間に何度保存しても、確認は 1 つ。
- 設定のダイアログを開いたまま衝突させる → 閉じた後に確認が出る（落ちない）。
- サーバー側で書き込めないようにして保存 → 通知とエラー表示の両方が出て、再読み込みの後も表示が残る。

## 4. 接続

- **FTPS の案内**: FTP の接続先を開くと、タイトルの右に「暗号化されていません」が出る。押すと調べて結果が出る。
  「FTPS に切り替える」→ 方式が FTPS（Explicit）になり、つなぎ直して一覧が出る。
  別の接続先で「今後表示しない」→ 印が消え、再起動後も出ない。
- ＋メニュー →「FTPS に切り替えられる接続先を調べる…」→「調べる」で 1 件ずつ結果が出る。
  会社の共有の接続先を選ぶと注意書きが出る。途中で閉じると止まる。切り替えた後、開いている接続先がつなぎ直される。
- 証明書を検証できるサーバーで「切り替えられる」になる（Mac では確かめられなかった）。
- 接続先の編集で、方式を FTP にすると注意書きが出て、他の方式では消える。
- **ホスト鍵**: SFTP の接続先で、`%APPDATA%\Ferry\known_hosts.json` の写しを取ってから、該当の値を別の文字列に書き換えて接続する。
  専用の表示が出て、フィンガープリントを選択・コピーできる。「新しい鍵を信頼して接続」でつながり、ファイルの値がサーバーの鍵に戻る。
  その後、転送とプレビューもつながる。

## 5. パスワードの保管庫

- 設定 → パスワード →「マスターパスワードを変更…」（自分用・会社用）。警告と 3 つの入力欄が出る。
  今のパスワードを間違える・7 文字以下・確認の不一致を試す。正しく入れると「変更しました」。
- **本物の会社の保管庫で試す前に、共有フォルダの `passwords.vault` の写しを取っておく。**
- 変更した後、Mac 版（0.14 以降）で「マスターパスワードが変更されたようです」と出て、新しいパスワードで開ける。逆（Mac で変更 → Windows）も。

## 6. 一覧

- 一覧をクリックして Ctrl+F → そのペインだけ入力欄が開く。虫眼鏡のボタンでも開閉できる。
- 入力するとその場で絞り込まれ、件数が「N 項目中 M 項目を表示」になる。合わなければ「…に合う項目はありません」。
- 項目を選んでから絞り込みを変えると、選択が外れる。その状態で Delete や転送を押しても、見えない項目に何も起きない。
- フォルダを移ると入力欄が空になる。F5 や転送の後の再読み込みでは残る。Esc で閉じて一覧にフォーカスが戻る。
- サイドバーの検索で、全角の「ＡＢＣ」でも半角の名前が見つかる。

## 7. その他

- 起動した後、`%TEMP%\Ferry` の `Preview`・`Edit`・`drag` の古い中身が消える。Ferry を 2 つ起動したとき、後の方は消さない。
- サーバーに `nul.txt` や `CON` という名前のファイルがあれば、ダウンロードすると `_nul.txt` のようになる（あれば）。

## 8. 取り扱い説明書の PDF を作り直す

`docs/manual/manual.html` に新しい機能の説明を足したが、PDF（`docs/manual/Ferry 取り扱い説明書.pdf`）は古いまま。
前回の PDF は Windows の Edge で作っているので（フォントが BIZ UDPGothic・Consolas・メイリオ）、Windows で作り直す。

1. `manual.html` の表紙の「Ferry for Windows 0.1.8 時点」を、次の版の番号に直す。
2. `docs\manual` で:
   ```
   & "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --print-to-pdf="$PWD\Ferry 取り扱い説明書.pdf" --no-pdf-header-footer "$PWD\manual.html"
   ```
3. PDF を開いて、ページの崩れが無いことを見る（13 ページから 17 ページくらいに増える）。
4. `release.ps1` がこの PDF を共有フォルダへ配る。
